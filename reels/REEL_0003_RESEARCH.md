## Evidence map

| Classification                 | Verified statement permitted in the reel                                                                                                                                    | Boundary                                                                                                                                |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| Strong evidence                | A meta-analysis of total acute sleep-deprivation studies found poorer memory for newly learned material when deprivation occurred before or after learning.                 | The study concerns total acute sleep deprivation; it does not establish a universal effect size for everyday small variations in sleep. |
| Expert interpretation / review | Reviews describe sleep as supporting consolidation of some newly learned memories, with reactivation and systems-level change discussed as mechanisms.                      | The mechanism is a model and its relevance varies by memory type, timing, task, and person.                                             |
| Emerging evidence              | Targeted memory reactivation experiments use previously learned cues during monitored sleep; a meta-analysis found an overall memory benefit in those laboratory paradigms. | Do not turn this into advice to play sounds while sleeping, a guarantee, or a consumer treatment claim.                                 |
| Not used                       | A claim that every memory gets stronger during every sleep period, or that sleep replaces learning effort.                                                                  | Excluded as unsupported overgeneralization.                                                                                             |
| Philosophy/spirituality        | No philosophical or spiritual claim is used.                                                                                                                                | None should be presented as neuroscience.                                                                                               |

## Sources
